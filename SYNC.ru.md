# Синхронизация Tempience между своими устройствами

Tempience хранит записи в браузере каждого устройства. Чтобы на телефоне и на
ноутбуке были одни и те же записи, на одном из ваших компьютеров работает
небольшой **сервер синхронизации**, а остальные устройства ходят к нему через
вашу личную сеть [Tailscale](https://tailscale.com). Ни автор, ни сайт, ни
кто-либо ещё в этом не участвует: сервер ваш, данные ваши, сеть ваша.

Инструкция рассчитана на человека, который ни разу не запускал сервер. Займёт
минут пятнадцать; в каждом шаге написано, что набрать, что вы увидите и что с
этим сделать. English version: [SYNC.md](./SYNC.md).

## Что понадобится

- **Компьютер, который не выключают** — домашний ноутбук или стационарный.
  Через него синхронизируются остальные устройства. Когда он выключен или
  спит, каждое устройство работает само по себе и догоняет остальных, как
  только сервер снова доступен.
- **Node.js 22 или новее** на этом компьютере. Скачайте установщик LTS с
  [nodejs.org](https://nodejs.org) и запустите. Проверка в терминале
  (macOS: Terminal; Windows: PowerShell; Linux: любая оболочка):

  ```sh
  node -v
  ```

  Должно напечатать `v22.…` или выше. Если команда не найдена — Node ещё не
  установлен, или терминал открыт раньше, чем закончилась установка: откройте
  новый.
- **Аккаунт Tailscale** — для личного пользования бесплатно; заведём в шаге 2.

## Шаг 1 — Запустить сервер синхронизации

В терминале на этом компьютере:

```sh
npx tempience-sync
```

Первый запуск скачивает сервер (около минуты). Потом он печатает:

```text
Tempience Triplit server listening on http://127.0.0.1:6544
Triplit database: /home/you/.local/share/tempience/triplit.sqlite
Config: /home/you/.local/share/tempience/config.json
Pairing code: kT9x2…
Pairing code expires: 2026-09-20T10:15:00.000Z
Status page: http://127.0.0.1:6544/
```

Откройте **http://127.0.0.1:6544/** в браузере *на этом же компьютере*. На
странице крупно показан **код подключения**, сколько минут он ещё действует,
кнопки **Скопировать** и **Новый код**. Код показывается только на этой
странице и никогда не уходит в сеть. Терминал пока не закрывайте: закроете —
сервер остановится.

**Чтобы сервер работал и после закрытия терминала (и после перезагрузки).**
Установите его насовсем и зарегистрируйте как фоновую службу:

```sh
npm install -g tempience-sync
tempience-sync --install-service
```

На Linux появится пользовательская служба systemd, на macOS — LaunchAgent; на
Windows команда напечатает одну строку `schtasks`, которую нужно выполнить.
Дальше сервер стартует вместе с вашим входом в систему.
`tempience-sync --status` показывает, где лежат база и конфиг и работает ли
служба; `tempience-sync --uninstall-service` убирает службу.

## Шаг 2 — Дать компьютеру https-адрес через Tailscale

Приложение на tempience.app открывается по HTTPS, и браузер не даст ему
обращаться к обычному адресу вроде `http://192.168.1.10:6544`. Tailscale
выдаёт компьютеру `https://`-адрес с настоящим сертификатом — и этот адрес
существует только внутри вашей сети устройств.

1. Установите Tailscale **на этот компьютер и на каждое устройство**, которое
   хотите синхронизировать (телефон, планшет, второй ноутбук):
   [tailscale.com/download](https://tailscale.com/download). Везде войдите
   **одним и тем же аккаунтом**.
2. В админ-консоли Tailscale откройте
   [DNS](https://login.tailscale.com/admin/dns) и включите **MagicDNS** и
   **HTTPS Certificates**.
3. На компьютере, где работает сервер:

   ```sh
   tailscale serve --bg 6544
   ```

   Команда напечатает примерно такое:

   ```text
   Available within your tailnet:

   https://laptop.tail1234.ts.net/
   |-- / proxy http://127.0.0.1:6544
   ```

   **Скопируйте адрес `https://….ts.net`** — это адрес сервера, который
   приложение спросит в шаге 3. Настройка переживает перезагрузки: команду
   выполняют один раз.

   *Linux:* если `tailscale serve` ругается на права (permission denied,
   operator), один раз выполните `sudo tailscale set --operator=$USER` и
   повторите команду.

Этот адрес доступен только с устройств, вошедших в ваш аккаунт Tailscale. Из
интернета сервера просто не существует. Не используйте `tailscale funnel` —
это открыло бы сервер всему интернету.

## Шаг 3 — Подключить каждое устройство

На каждом устройстве откройте **https://tempience.app/pair** (в приложении:
нажмите индикатор синхронизации в шапке, затем **Pair**). Заполните:

- **Адрес сервера синхронизации** — адрес `https://….ts.net` из шага 2.
- **Pairing-код** — со страницы на компьютере (http://127.0.0.1:6544/). Код
  живёт 10 минут; если истёк — нажмите там **Новый код** и введите новый.
  Один код можно использовать для нескольких устройств, пока он действует.
- **Название устройства** — любое, например «Телефон».

Нажмите **Подключить устройство**. Приложение перезагрузится, индикатор в
шапке сменится с **Только локально** на **Подключение…**, а затем на
**Синхронизировано**. Записи, которые уже были на устройстве, уйдут на сервер;
записи с сервера появятся на устройстве. Повторите на каждом устройстве.

## Чего ожидать

- **Нет сети или компьютер выключен** — приложение работает как обычно;
  изменения ждут в очереди и доставляются при следующем соединении. Индикатор
  тем временем показывает **Оффлайн** или **Подключение…** и число изменений в
  очереди.
- **Устройство остаётся подключённым 90 дней.** Потом приложение снова
  покажет **Только локально**; откройте `/pair`, возьмите свежий код,
  подключите — ничего не пропадёт. Перезапуск сервера печатает новый код, но
  уже подключённые устройства не трогает.
- **Сервер — не резервная копия.** В нём те же живые данные, что и на
  устройствах; удалили запись — она удалилась везде. Регулярно выгружайте JSON
  (индикатор синхронизации → **Экспортировать данные**) и храните файл в
  надёжном месте.
- **Где что лежит.** `config.json` (сгенерированный секрет, порт, сроки жизни
  кода и ключа) и `triplit.sqlite` (ваши данные) — в
  `~/.local/share/tempience` на Linux, `~/Library/Application Support/Tempience`
  на macOS, `%APPDATA%\Tempience` на Windows. `tempience-sync --status`
  печатает точные пути. Смена секрета в `config.json` и перезапуск сервера
  отключают все устройства разом — так отзывают доступ.

## Если что-то пошло не так

**На странице компьютера вместо таймера — `Истёк — нажмите «Новый код»`.**
Нажмите **Новый код**; на устройстве введите новый.

**Приложение пишет `Подключение не удалось: invalid_pairing_code`.**
Код набран с ошибкой или взят от прежнего запуска сервера (каждый запуск
делает новый). Скопируйте код с http://127.0.0.1:6544/ заново.

**Приложение пишет `Подключение не удалось: pairing_code_expired`.**
Десять минут кода прошли. Нажмите на странице **Новый код** и повторите.

**Приложение пишет `Адрес сервера должен начинаться с https:// (http:// допустим только для localhost).`**
Введён `http://…` или IP-адрес. Нужен адрес `https://….ts.net`, который
напечатал `tailscale serve` (шаг 2).

**Приложение пишет `Адрес сервера должен быть полным URL, например https://laptop.your-tailnet.ts.net.`**
В начале должно быть `https://`, а после имени хоста — ничего: ни пробелов,
ни `?`.

**Приложение пишет `Непредвиденная ошибка: Failed to fetch`, или кнопка крутится и ничего не происходит.**
Устройство не дотягивается до компьютера. Откройте на устройстве приложение
Tailscale: оно должно показывать **Connected**, и аккаунт должен быть тот же,
что на компьютере. Затем откройте адрес `https://….ts.net` в браузере
устройства: должно появиться «Сервер синхронизации Tempience работает». Если
страница не открывается — в админ-консоли ещё выключены MagicDNS или HTTPS
Certificates (шаг 2.2), Tailscale выключен на одном из двух устройств, или
сервер на компьютере не запущен (`tempience-sync --status`).

**После подключения индикатор всё равно показывает `Только локально`.**
Нажмите индикатор и прочитайте детали. «Ошибка синхронизации: …» с текстом про
авторизацию означает, что ключ устройства выдан другим сервером (секрет
сменился или сервер поставили заново): на `/pair` нажмите **Отвязать это
устройство** и подключите заново со свежим кодом.

**Сервер печатает `Port 6544 is already in use.`**
Сервер уже запущен — скорее всего, служба из шага 1; `tempience-sync --status`
подскажет. Чтобы запустить второй, стартуйте его с `npx tempience-sync --port
6545` и укажите этот порт в `tailscale serve`.

**`npm install -g` падает с `EACCES` / permission denied (Linux).**
Node установлен системным пакетным менеджером. Ставьте в домашнюю папку:
`npm install -g --prefix ~/.local tempience-sync`, затем
`~/.local/bin/tempience-sync --install-service`.

**`tailscale serve` пишет, что HTTPS certificates или MagicDNS не включены.**
Шаг 2.2: [настройки DNS](https://login.tailscale.com/admin/dns) в
админ-консоли.

**Что-то ещё.** `tempience-sync --status` на компьютере, а на Linux
`journalctl --user -u tempience-sync -n 50` (macOS:
`~/Library/Logs/tempience-sync.log`) покажут, что говорит сервер.
