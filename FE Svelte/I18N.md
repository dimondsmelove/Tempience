# Internationalization

Tracked by #32 within the scoped MVP #34 / PR #36. The runtime is adapted from
the existing `feat/i18n` donor (`2d2f40e`, final donor `c53ddb9`) onto the current
forms branch. The donor is retained; its old UI is not merged wholesale.

## Current implementation

`src/lib/state/Locale/` owns static RU/EN catalogs and the browser language
preference. Russian is the default and fallback. The explicit choice is stored
under `tempience-locale`; switching language does not reload the app or change
DataSpace, user data, navigation or an open draft. Storage denial permits a
session-only choice. The root restores the preference before creating children
and updates `document.documentElement.lang`.

The pinned i18next runtime uses typed message keys. Both catalogs ship in the
bundle, including plural forms and interpolation parameters. The current app
disables SSR; the singleton belongs to the browser session. Enabling SSR would
require revisiting that ownership.

The catalogs are split by area (`messages/{ru,en}/{common,draft,result,history,
scope,errors,validation,forms,theme,time,context,timeline,life}.json`) and merged
into one flat key space; a unit test proves both languages carry the same keys
and no area repeats another's. The mechanisms the live surfaces rely on:

- Coded refusals (`model/Errors/CodedError`, `RepositoryError`) carry a `code`
  and `details`; `state/Locale/errors.ts` `errorText(cause)` reads the copy for
  `error.<code>` with `details` as parameters and `details.reason` as the
  variant. A plain `Error` is named as unexpected with its message; the log
  message of a coded error is never the copy. Readers, commands and components
  keep the cause (`failure: unknown`), not words, so a switch rewords it.
- Typed-form validation (`forms/TraceForms/validation.ts`) rewrites AJV's
  messages into a key-and-parameters payload before SJSF reads them; the
  errors list decodes them in the language of the moment, without
  re-validating or remounting the control. The installed validator rewrites a
  missing field's message once more (`replace(missingProperty, title)`, the
  first occurrence of the raw key, whatever the key is), so that message
  starts with the key as a decoy that absorbs the rewrite and carries the
  payload last, after a separator the payload never contains; the list names
  the field from its own configuration (its title, or a child's title as the
  form labels it), never from the message. SJSF's own array/object words come
  from its ru/en translations.
- Model functions that produce words take `language: Locale` (`traceSummary`,
  `traceFormDisplay`, `formatFormValue`, axis labels, life grid, time labels);
  the model imports only the pure `messages.ts`, and UI/state callers pass
  `locale.current`. Loaded records are redisplayed in memory on a switch
  (`WorkbenchState.redisplay`, `Records.redisplay`), with no reads.
- `state/Locale/format.ts` caches `Intl` formatters per language and options;
  hot paths never create a formatter per record.

## Adding interface copy

```svelte
<script lang="ts">
	import { t } from '$lib/state/Locale/Locale.svelte';
</script>

<button>{t('shell.appearance')}</button>
<span>{t('common.records', { count: rows.length })}</span>
```

- Add complete messages to both catalogs, with stable semantic keys and named
  parameters. Avoid translating sentence fragments independently.
- Translate at display time. Module-level translated strings freeze the
  initial language; keep key maps and call `t()` in reactive consumers.
- Keep user-authored titles, descriptions, Scope/Kind names and field values
  separate from interface labels. Do not translate persisted data or IDs.
- Svelte escapes text; i18next's extra escaping is disabled. Do not render
  translations or interpolated parameters using `{@html}`.
- Display repository errors through the coded boundary: raise a `CodedError`
  with a code that has copy in both catalogs and store the cause. A localized
  fallback alone does not translate a raw `Error.message` or a message that
  was already stored in the previous language.

`translate(language, key, options)` serves explicit-language adapters outside
components. Locale affects presentation, not timezone, UTC boundaries, ISO
weeks, date precision, ordering or assessment semantics. English natural
language Capture parsing and RTL remain outside this increment.

## Verification and completion

Run unit/check/build and scoped lint/format checks. Run svelte-autofixer on
every changed `.svelte` and `.svelte.ts` file before each commit. Restart a
production preview after each build; it loads the asset manifest at startup.

The locale browser specs (`e2e/time/locale*.spec.ts`, one scenario each, shared
words in `locale.helpers.ts`) check switching with an open draft, shell layout
and offline reload; the rendered desktop/phone sweep — a Kind history with its
page and filters, an invalid typed form and the builder's check with quoted
titles, SJSF array controls, nested authoring, a pending Undo offer, the month
wheel, the backup menu, the Context tabs on a phone, a reload, and the stored
rows compared whole across switches; and, on a dev server only (the app's
modules by URL, `boundary.helpers.ts`, `locale-dev.helpers.ts`), the words at
the storage boundary — a pattern refusal, missing fields keyed by envelope
words, one character, the empty string and the separator, a group's missing
child, a title-less unit field, a refused save, a committed-open retry, a stale
Undo, a restored record not shown — and that a switch asks the repository for
nothing while a record is selected, a form is open or a history is paged. The
runtime validates leaf fields on input and blur only (no `ON_OBJECT_CHANGE`),
so an object's own message about a missing child is proved through the
installed transformer in the unit test, not rendered.
Do not treat a successful switch as proof of full translation: what stays
literal by engineering scope is developer log text inside coded refusals,
corruption details of stored assessments, the experiments prototype, stored
data labels and fixtures; every failure prose the current UI shows is copy.
